## About Me

I don't just write code - I design it to look right, and I build the businesses around it too.

I'm a **Freelance Full Stack Developer currently working as an Independent Contractor with Umuzi** in web development, building responsive, production-grade applications from front end to database. My background in **graphic design** means I bring an actual eye for layout, spacing, and user experience into everything I build - the things I ship aren't just functional, they're intentional.

I work across **web, desktop, and mobile development**, using technologies such as **React, Node.js, C#, ASP.NET Core, .NET MAUI, WPF, SQL Server, and Microsoft Azure**. I enjoy designing complete systems, from the user interface and application architecture to APIs, databases, and deployment.

Beyond development, I'm the **Founder of Nene IT & Consulting**, an IT startup, and the **Founder of Blaqcodex**, a clothing brand - because building things I care about doesn't stop at code. My academic foundation in **Computer Science, Applied Mathematics, and Statistics** keeps my thinking structured, whether I'm debugging an API or making a business decision.

🇿🇦 Based in Durban, South Africa  
🎓 UKZN, DUT (Computer Science & Information Technology)  
🎯 Currently building scalable applications, exploring cloud technologies, growing two ventures, and always shipping.
